# End-to-end tests

Playwright tests that drive the real app in Chromium.

## Running

From `web/`, with the dev database running (`docker compose -f ../docker-compose.dev.yml up -d`):

```bash
npx playwright install chromium   # first time only
npm run e2e                       # every spec except the release path
npx playwright test e2e/records-crud.spec.ts
npm run e2e:release               # full journey from an empty database
```

Playwright starts its own servers (see `../playwright.config.ts`):

| Service | Port | Notes |
|---|---|---|
| Fake Discogs | 8020 | `api/scripts/mock_discogs.py` — OAuth, a 230-record collection, search |
| API | 8010 | fresh `groove_e2e` database on each run |
| Vite dev server | 5180 | proxies `/api` to 8010 |

Set `E2E_PG_PORT` to use a Postgres on another port.

## Specs

| File | Covers |
|---|---|
| `auth-screens.spec.ts` | Sign-in / register screens (with visual snapshots) |
| `invite-flow.spec.ts` | Inviting a family member |
| `password-reset.spec.ts` | Reset link generated by another member |
| `records-crud.spec.ts` | Add, edit, delete records by hand |
| `records-discogs.spec.ts` | Discogs search and add |
| `record-ownership.spec.ts` | Showing and changing a record's owner |
| `views-browse.spec.ts` | Grid/list views, search and filters |
| `views-responsive.spec.ts` | Phone layout |
| `views-purchases-map.spec.ts` | Purchases and the map |
| `shelf.spec.ts` | 3D shelf |
| `language.spec.ts` | Switching language |
| `settings-backup.spec.ts` | Backup export/import |
| `release-path.spec.ts` | Whole journey from an empty database (run alone) |

The browser locale is `it-IT`, so tests read Italian texts. Traces are kept on failure in
`test-results/`.
