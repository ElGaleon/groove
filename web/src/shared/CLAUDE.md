# CLAUDE.md — web/src/shared/

Generic code used by many features. **Must not import `@/features/*` or `@/app/*`.**

- `ui/` — shadcn primitives (base-ui based). Generated by `npx shadcn add`; small edits are fine,
  keep their API. Exempt from the no-literal-text test, so keep them text-free anyway.
- `components/` — app-level building blocks (`Page`, `Field`, `PasswordField`, `SubmitButton`,
  `ResponsiveModal`, `Notice`, `LanguageSelect`, `SearchField`, …). Prefer reusing these over new ones.
- `hooks/` — generic hooks (`use-mobile`).
- `lib/`
  - `api.ts` — `api()` fetch wrapper (CSRF header, zod validation, `ApiError`,
    `ResponseShapeError`) and `errorMessage()` (translates API error codes).
  - `routes.ts` — every app URL + legacy redirects. Add new routes here.
  - `queries.ts` — `invalidateCollection()` and query-key list.
  - `money.ts` — minor-unit amounts and currency formatting.
  - `utils.ts` — `cn()`.
- `schemas/` — `openapi.json` (snapshot of the API) and `generated/` (zod, from
  `npm run schemas`). Never hand-edit `generated/`; re-export what you need from `index.ts`.
